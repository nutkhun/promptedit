# 04 — UI, theme, interactions, shortcuts, settings, updates

Source of truth: `Editroom/UI/*.swift`, `Editroom/App/*.swift`, `Info.plist`, `Editroom/Assets.xcassets`,
`design/*` mockups, `docs/screenshot.webp` (Editroom 1.0.11, build 12, bundle id `com.wonderassembly.Editroom`,
macOS 14+). Where a mockup and the Swift code disagree, **the code wins** (the mockups are earlier design
explorations; divergences are noted). All sizes are points (= CSS px at 1×). Uncertain items are marked **UNSURE**.

Conventions used below:
- `ink(a)` = the theme's `ink` colour at opacity `a` (white on dark themes, black on Light). Almost every hover,
  stroke and quiet fill is an `ink` tint.
- "hover anim" = `easeOut 120 ms` on hover-state change (used on every hoverable control).
- "continuous" corners = Apple squircle; in CSS a plain `border-radius` of the same value is acceptable.

## 1. Window layout

### 1.1 Main window

| Property | Value |
|---|---|
| Single window, id `main`, title "Editroom" | One editor window only. Close (⌘W / "Close", "Close All") is removed from menus; ⌘Q quits. |
| Default size | 1480 × 940 |
| Minimum content size | 1080 × 680 |
| First ever launch | Window fills the screen's visible frame (minus menu bar/Dock); flag `filledScreenOnFirstLaunch`. Afterwards the OS remembers size/position. Windows equivalent: maximise on first launch, then persist bounds (e.g. tauri-plugin-window-state). |
| Title bar | Unified toolbar, title hidden, transparent title bar, background = `panel`. A 1px solid hairline under it (`#1F1F1F` on Dark; on other themes `panel` blended with `ink` at `strokeAlpha × 0.72`). |
| Window background | `panel` colour; the content area background is `bg`. |

**Title-bar contents (toolbar):**
- Centre (principal): project title (`file name without extension` or "Untitled"), 13 pt medium, `textDim`; followed
  (6 pt gap) by a 5 pt dirty dot in `textFaint` when there are unsaved changes.
- Right (primary actions, in order): **Export progress pill** (only while the export queue is non-empty, see §1.7),
  **Magic button** (only when Settings › Magic › Enable Magic is on; 8 pt trailing pad), **Export** pill button
  (prominent white pill, 10 pt trailing pad, tooltip "Export (⌘E)").
- Left: macOS traffic lights. On Windows: put window controls on the right after Export (custom title bar in Tauri,
  `decorations: false` + drag region) — **UNSURE** exact Windows chrome; keep the same 1-row height (~52 pt incl.
  title bar per screenshot; macOS unified toolbar height is ~52).

**Magic button** (out of scope detail, but visible chrome): capsule, height 26, horizontal padding 11, fill
`ink(0.08)` (hover `ink(0.14)`), 1px stroke `ink(0.05)`; content = SF symbol `wand.and.sparkles` 11 pt semibold +
"Magic" 11.5 pt semibold `text`. While working: spinner + worker name ("Claude"/"ChatGPT"/"Local"); on hover while
working it shows a stop icon (accent) + "Stop". To its left a status text 11.5 pt `text` @ 60% (max 40 chars,
ellipsised). Disabled (40% opacity) with no media. Opens the Magic popover (separate spec).

### 1.2 Main split

```
┌──────────────────────────── title bar / toolbar ────────────────────────────┐
├─ Library ─┬───────────── Viewer ─────────────┬─ Inspector ─┤
│ 252 (190…440, draggable)   flexible            │ 320 fixed   │
├───────────┴──────────── horizontal splitter ───┴─────────────┤
│ Timeline panel  (default height 360, draggable)              │
└───────────────────────────────────────────────────────────────┘
```

- **Library width**: default 252; splitter drag sets `clamp(x − windowLeft, 190, 440)`. Not persisted (resets on
  launch). Test flag `--library-width N`.
- Library ↔ viewer: `Splitter` (1px line `stroke`, 9 pt invisible hit area, resize-left-right cursor on hover, the
  line turns `ink(0.45)` while dragged). Viewer ↔ inspector: plain 1px vertical `Hairline` (not draggable).
- **Inspector width**: fixed 320.
- **Timeline height**: default 360; horizontal splitter (resize-up-down cursor). On drag:
  `timelineHeight = min(max(200, windowH − 240), max(170, windowBottom − y))`. Rendered height is
  `min(timelineHeight, max(170, windowH − 240))`, i.e. the upper area always keeps ≥ 240 pt and the timeline ≥ 170.
  Not persisted.
- While Magic is working ("editor locked") splitters ignore hover/drag and the upper area + timeline ignore hit
  testing.
- **Theme change** rebuilds all views (`.id(themes.look)`).

All three upper panels share a **44 pt header row** with one common baseline (polish mock: "one grid, one baseline";
4-pt spacing grid: 4, 8, 12, 16).

### 1.3 Library (Media panel)

Background `panel`. Tracks its own width/height.

**Header (44 pt, padding leading 16 / trailing 12):**
- Title "MEDIA" (`label` font 10 pt semibold, uppercase, tracking 1.6, `textDim`). Inside a folder it becomes a back
  chevron button (20×20, radius 6, chevron 10 pt semibold; tooltip "Back to <parent>" / "Back to Media") + folder
  name uppercased in the same label style (truncate middle, tooltip = full path label).
- Spinner (small, scale 0.6, 14×14) while any import runs.
- Right: **Add Text** (text-frame icon), **Add Solid** (solid icon), **Import** (`square.and.arrow.down` line icon,
  `IconButton` size 26, tooltip "Import Media (⌘I)"). Add buttons are 26×26, radius 7, glyph 12, hover fill `hover`;
  click adds at playhead; they are also draggable onto the timeline (drag payload `editroom:text` / `editroom:solid`).
- Right-click on header or empty panel space → menu: Add Text · Add Solid · Import Media… (⌘I) · — · "View as"
  inline picker: Thumbnails / List.

**Body (scroll view, padding h12, bottom 12, vertical spacing 12):**
- Empty project: search field + centred "Imported media\nappears here" (11.5 pt, `textFaint`, top pad 16).
- Missing linked folder banner (when inside a folder whose root is gone): `raised` box radius 7, padding 9/7,
  yellow warning triangle 10.5 pt, "“<name>” can't be found" 11 pt, and a **Locate…** capsule (fill `text`, label
  `onText` 11 pt medium).
- **Search field**: height 26, radius 7, fill `field`, focused stroke `text @ 0.85`; magnifier 10.5 pt `textFaint`
  (switches to `text.bubble` in `text` colour once a quote `"`/`“` is typed: transcript search); placeholder
  "Search" or "Search folder"; clear (x-circle) button when non-empty; Esc clears and unfocuses.
  - Search semantics: words in quotes match what is *said* (transcripts); other words match the file name or
    scene tags (each word, prefix-typing allowed). While searching, results come from the whole open folder subtree
    and show their folder ("place" line, 10.5 pt `textFaint`, truncate head) and a transcript snippet
    (`“…before **match** after…”`, 10 pt `textDim`, match bold `text`, max 2 lines).
  - No results: "Nothing says <query>" (quote search) or "No media matches “<query>”" (11.5 pt `textFaint`).
- **Thumbnails layout** (default): `LazyVGrid` adaptive columns min 88, column spacing 8, row spacing 10.
  - Asset tile: padding 3, background radius 8 (picked `ink(0.12)`, hover `hover`); picture 16:9, radius 6, clip
    fill black@0.5 behind; duration badge bottom-right (mono 9.5, `#F2F2F0` on black@0.55, radius 3, padding 4/1.5,
    inset 5) for non-images; picked outline `ink(0.85)` 1.5 px; name 11 pt medium (`textDim`, `text` when
    hovered/picked), truncate middle.
  - Folder tile: same frame; picture = faint fill `ink(0.02)`, `folder` symbol 21 pt light `textDim@0.8`; name + item
    count (mono 10 `textFaint`) at right; missing → black@0.45 + yellow triangle.
  - Incoming tile (file still being written by another app, e.g. Photos): dim box with spinner, "Importing…"
    (`textFaint`), tooltip explains; right-click "Cancel Import" / "Cancel N Imports".
- **List layout**: rows spacing 3, padding 4, radius 7 (picked `ink(0.12)` + 1px `ink(0.18)` stroke; hover `hover`).
  Thumb width `clamp(64 + (panelWidth − 252) × 0.21, 64, 104)`, height = width × 9/16 rounded, radius 5. Name
  11.5 pt medium; detail mono 10 `textFaint`: video "m:ss", audio "m:ss  ·  Audio", image "Photo". Folder rows:
  "N items" / "Missing". Tooltip on asset rows: "name · m:ss · W×H · N fps" (+ "Audio").
- Thumbnail placeholders when no poster: SF symbol `film`/`photo`/`waveform` 20 pt (13 in list).
- **Offline media**: black@0.6 overlay + yellow `exclamationmark.triangle.fill`.
- **Hover scrub** (video assets only, not offline): moving across the picture scrubs it; a 1.5 px white vertical line
  marks the position; the frame is also shown full-size in the main viewer (labelled, see §1.4); leaving clears.
  Fraction quantised to 60 steps for cached frames.
- **Selection**: click picks (⇧ range, ⌘ toggle) across folders, assets, incoming in display order; click on empty
  space (or right-click) clears media picks only. Clicking the timeline clears media picks.
- **Double-click** asset → add at playhead. Double-click folder → open it.
- **Drag** asset(s) → timeline; dragging one of several picked assets drags all picked, in panel order. Pasteboard
  string `editroom:<uuid>,<uuid>…`.
- **Asset context menu**: (offline) Locate… — · Add to Timeline · Match Sequence to Clip (video; disabled when the
  sequence already matches) · Show in Finder (Windows: "Show in Explorer") · Reload from Disk / "Reload N Items from
  Disk" (not offline) · — · Delete / "Delete N Items".
- **Folder context menu**: (missing) Locate… — · Open · Reload Folder from Disk · Show in Finder · — · Delete Folder /
  "Delete N Items". Tooltip: "<name> · N items. Double-click to open; it follows the folder on your Mac." or
  "<name> can't be found. Right-click to locate it."
- **Drop overlay** (files dragged over panel, or anywhere in the window that imports): bottom gradient 150 tall
  (black 0.92 → 0.7 @45% → 0), "⤓ Add to Media" (11 pt semibold icon + 12 pt semibold text, `#F2F2F0`, 22 pt from
  bottom), 2 px accent@0.9 border around the panel. Dropping imports (`importFiles`).
- After a manual import the new items are picked and scrolled into view (`mediaReveal`, 250 ms ease-out); an
  agent's import leaves the panel alone.

### 1.4 Viewer

- Background `bg` (pure black in viewer-only full-screen). Picture area padding: horizontal 16, top 16. Below it the
  **transport bar** (76 pt tall, padding h16).
- Picture: black surface, aspect = sequence aspect, fit into available space (or a zoom level). **Square corners**
  (matching exports), with a faint 1px `ink(0.05)` edge drawn just *outside* the picture. Zoomed larger than the
  space → scrollable both ways with visible scrollbars. Last frame stays visible while compositions rebuild (never
  flash black). Frames whose aspect differs >2% from the viewer are not shown (black instead of stretched).
- **Viewer zoom menu**: Fit (default), 25%, 50%, 100%, 200%. 100% = one frame pixel per *screen* pixel
  (`width = projectWidth × zoom / backingScale`). Windows/web: divide by `devicePixelRatio`.
- **Empty timeline prompt** (no clips, no source preview): dashed rounded rect 62% × 58% of the picture, radius 16,
  stroke 1.5 px dash [5,4], colour `outline` (hover `ink(0.3)`); inside (spacing 16): film-frame-with-arrow drawing
  96×70 (1.3 px strokes; frame `textFaint`, arrow `text`), headline 13 pt semibold `text`, sub 11.5 pt `textFaint`.
  - No media: "Drop video, audio or images anywhere" / "or press ⌘I to import  ·  MP4, MOV, MKV, WebM, WAV, MP3, JPG,
    PNG"; click → import panel. (Windows: "Ctrl+I".)
  - Has media: "Drag media from the library to the timeline" / "or double-click it to add it at the playhead".
  - The viewer is black in every theme, so on Light this prompt uses Dark palette colours.
- **Source preview label** (library hover-scrub or trim-edge frame): top-left, inset 10, height 24, radius 6,
  black@0.65; asset name 11.5 semibold (omitted for trims) + timecode mono 11.5 (`#9A9A96`; `#F2F2F0` for trims, with
  note "In"/"Out"); text `#F2F2F0`.
- **Direct manipulation**: with exactly one visual clip selected, dragging in the viewer (min distance 2) moves it:
  - Text clip: changes normalised `text.x/y` (0…1, clamped).
  - Video/image/solid: changes transform offset; snaps to centre when within 5 pt; if scaled ≥ 100% ("fills") it
    cannot be dragged past the frame edge (`|x|,|y| ≤ (scale−1)/2`); values rounded to whole frame pixels; a zooming
    clip is shown at its full zoom while dragging. One undo step per drag.

**Transport bar** (ZStack: left/right row + centred transport):
- Left: **timecode field** (mono 20 medium, tracking 0.4, `text`, height 26, padding h7, radius 6; hover/editing
  fill `field`, editing stroke `text@0.85`; tooltip "Click to type a time"). Click to type; Return/blur jumps, Esc
  cancels. Then "/ <duration>" mono 11.5 regular `textFaint` (baseline-aligned).
- Centre: Previous Edit (`backward.end.fill`), Back One Frame (`backward.frame.fill`) — IconButtons 32 —, **Play
  button**, Forward One Frame, Next Edit. Spacing 4; play has 10 pt extra padding each side.
  - Play button: 46 circle filled `text` (hover `ink`), glyph `play.fill`/`pause.fill` 17 pt bold in `onText`
    (play glyph nudged +1.5 x); 5 pt ring of `transport` colour with 1px `ink(0.05)` stroke; hover scale 1.05.
- Right: Loop toggle (`repeat` icon, active state), stereo output meters (two 4-wide `LevelMeter`s, 2 apart, height
  24, padding h4), viewer zoom menu (label 11.5 medium + chevron 7.5 bold, `textDim`, height 24, padding h8, radius 6,
  fill `field`), Full Screen toggle (`arrow.up.left.and.arrow.down.right` / exit icon).
- Tooltips: "Previous Edit (↑ or ⇧←)", "Back One Frame (←)", "Play / Pause (Space)", "Forward One Frame (→)",
  "Next Edit (↓ or ⇧→)", "Loop Playback (L)", "Output level, left and right", "Viewer zoom", "Full Screen Viewer
  (F)" / "Exit Full Screen (F or Esc)".

**Full-screen viewer** (`F`): not OS full screen. The window instantly covers the whole screen (Dock and menu bar
hidden, toolbar and window buttons hidden, full-size content), a black borderless click-through cover window behind
it fills the rounded corners (inner hole radius 26). Only the viewer + transport show (`viewerOnly`). Exiting (F or
Esc) restores the exact previous frame and chrome. If the window was already in OS full screen, only the toolbar is
hidden. Tauri: use `set_fullscreen(true)`/borderless + hide custom title bar — **UNSURE** behaviour parity on Windows.

### 1.5 Inspector

Width 320, background `panel`.

- **Header** (44 pt, padding h16, spacing 9): icon (18 wide, 12 pt medium, `textDim`) + title 13 pt semibold `text`,
  one line.
  - Title: no selection → "Sequence"; captions focused → "Caption" / "N captions" / "Captions"; one clip or one
    linked group → clip name; several → "N clips".
  - Icon: `rectangle.on.rectangle` (sequence), `captions.bubble`, `square.stack` (several groups), `film`,
    `waveform`, `photo`, text-frame icon, solid icon.
- **Body**: scroll view, padding h16, top 4, bottom 18; sections spaced 22.

**Section header** (`InspectorSection`): button row height 16: chevron-right 7.5 pt bold (rotates 90° open), 8 wide;
title UPPERCASE, `label` 10 semibold, tracking 1.6; colour `textFaint` (hover `textDim`); when collapsed *and*
changed, a 5 pt accent dot after the title. Optional right-side text link (e.g. "Reset", 11.5 medium, `textDim`,
hover accent) shown only when expanded. Collapse animation easeOut 80 ms (content fades + slides from top). Section
content spacing 10. Collapsed state persisted per title: key `inspector.collapsed.<Title>`.

**Shared controls:**
- **ParamRow** (height 28, spacing 8): icon (18 wide, 11 pt, `textDim`) · label 11.5 pt `text`, width 52 · ThinSlider
  (flex) · value field 68×26 radius 7 fill `field` (mono 11.5 `text`, right-aligned; focused stroke `text@0.85`;
  optional inline button at its right) · optional trailing control.
  - ThinSlider: height 20; track 2 pt `ink(0.12)`; fill 2 pt `text` up to knob centre; knob 13 circle `text` with a
    3 pt `panel` ring; hover/drag scale 1.12. Drag anywhere (min distance 0). Optional log mapping.
  - Value field always editable (Tab moves between rows). Return/blur applies; Esc reverts. Parses digits out of
    any text ("100%", "0.50s", "−18.8 dB"; `,` → `.`, `−` → `-`), clamped to range.
  - ↑/↓ while focused: step to the next whole step (1 for integer display, 0.1 for decimal display, or the row's
    explicit step); Shift ×10.
  - Each slider drag is one undo step (`live` → `commitLive` on release).
- **MenuField**: height 28 (26 in rows), radius 8, fill `field` (hover `hover`), stroke `ink(0.05)`, padding h11,
  label 11.5 `text` (truncate middle), chevron-down 8.5 bold `textDim`.
- **Chip** (toggle): height 26, padding h10, radius 7, 10 pt medium; off fill `field` text `textDim` (hover
  `hover`/`text`); on fill `accent@0.16` text accent.
- **CurveMenu** (fade shape): 48×26, radius 7, fill `field` (hover `hover`); curve glyph 20×12 (accent when the fade
  is active, else `textDim`) + chevron. Opens a native pop-up menu: Linear, Exponential, Logarithmic, S-Curve, each
  with its curve drawn before the name; current is ticked.
- **Colour well**: native colour picker, no opacity. Windows/web: custom popover colour picker — **UNSURE** which
  library; must not support alpha.
- **RampButton** (inside a value field): 18×18 radius 4; glyph = small ramp curve 11×8, 1.4 stroke; on = accent
  stroke + `accent@0.16` fill; off = `textDim` + `ink(0.06)` (hover 0.12).

**Which sections appear:**

| Context | Sections (in order) |
|---|---|
| Nothing selected, captions not focused | **Frame**, **Frame rate** |
| Nothing selected, caption track focused / captions picked | **Caption** (only if exactly one picked), **Style** |
| Clip(s) selected | **Text** (single text clip) · **Solid** (single solid) · **Playback** (if any source-playing clip or audio) · **Transform** (transformable visual clips) *or* **Transform** for a single text clip · **Transitions** (exactly one visual clip that touches a neighbour) · **Fade** / **Video fade** · **Audio fade** · **Grade** (any visual clip) |

#### Frame (sequence)
- MenuField showing "W × H" with presets: `4K  3840 × 2160`, `1440p  2560 × 1440`, `1080p  1920 × 1080`,
  `720p  1280 × 720`, `Vertical  1080 × 1920`, `Vertical 4K  2160 × 3840`, `Square  1080 × 1080`.
- Two numeric fields "W × H" (height 28, radius 8, mono 11.5 centred; "×" 11.5 `textFaint` between). Values forced
  even, clamped 16…8192. ↑/↓ = ±2 (Shift ±20). Return/blur applies, Esc reverts.
- Default new project: 1920 × 1080.

#### Frame rate (sequence)
- MenuField: 23.976, 24, 25, 29.97, 30, 50, 59.94, 60, 100, 119.88, 120 — label "24 fps" / "29.97 fps" (integers
  without decimals, otherwise 2 decimals). Default 30.
- Hint (10 pt `textFaint`) "Matches the first video you import." while the sequence isn't locked and has no video.

#### Caption / Style (caption track)
- **Caption**: multi-line text field (1–4 lines, 12 pt medium, padding 8/7, radius 8, fill `field`) with the picked
  caption's words; editing previews live in the viewer and moves the playhead into the caption if outside;
  Return/blur commits (one undo step); emptied → the caption's words are left out; Esc reverts. Note under it (10.5
  pt `textFaint`): "Fixed here, a word stays fixed wherever this clip is used. Delete leaves the caption's words out."
  Double-clicking a caption on the timeline focuses this field.
- **Style** (applies to whole track):
  - Size: 28…140, default 64, integer.
  - Position: 10…95 %, default 78 % (stored y 0.78, rounded to 0.001).
  - Text colour row: default white.
  - Word highlight row: eye toggle (default on) + colour, default `#FFD640` (rgb 1, 0.84, 0.25).
  - Outline row: eye toggle (default on) + colour, default black.
  - Colour rows: icon 18 · label 11.5 · spacer · (eye 20×20, `eye`/`eye.slash` 9.5 pt; on `textDim`, off
    `textFaint`, hover +10% brightness) · colour well 44 wide (40% opacity when off). Off rows dim label/icon to
    `textFaint`.
  - While transcripts pending: "Listening for what's said in the captioned clips…" (10.5 `textFaint`).

#### Text (single text clip)
- Text editor, 11.5 pt, height 68, padding 6, radius 8, fill `field`.
- Font picker field (height 28, like MenuField) showing family or "System"; opens a popover (arrow on leading edge)
  260×360: search field (height 34, "Search fonts", magnifier) · hairline · list of families, each row 28 tall, name in
  its own face at 14 pt, checkmark (accent) on current; Return picks first match; "No fonts match". Includes
  "System" first. Windows: enumerate system fonts via Rust (e.g. `font-kit`) — **UNSURE**.
- Row: **Bold** chip + colour well (default white).
- Size: 12…600 log, default 110 (relative to a 1080-tall frame), integer.
- Text clip **Transform** section (collapsed by default): X −w/2…w/2 px, Y −h/2…h/2 px from centre (default 0,0);
  Reset → centre.

#### Solid (single solid clip)
- One row: `paintbrush` icon · "Fill" · colour well (no alpha). Default clip colour rgb(0.16, 0.16, 0.20) ≈ `#292933`.

#### Playback
- Reset link when speed ≠ 100%, ramped, or gain ≠ 0 (resets speed, ramp and selected audio volume). Marked likewise.
- **Volume** (audio clips): −60…+12 dB, default 0; display via `formatDB` ("+3.0 dB", "−6.0 dB", "0.0 dB",
  "−∞ dB" at ≤ −59.5); stored to 0.1 dB; applies to all selected audio clips.
- **Speed** (source-playing clips: video/audio not frozen): 10 %…5000 %, logarithmic, integer %, default 100 %.
  Applied relative to the clips as they were at drag start (no rounding drift); linked clips change together;
  respects Sticky. Inline RampButton toggles a speed ramp.
  - Ramp on: starter shape from last-picked mode (`speedRampMode`, default "in"): In → points (0.3, 0.6, 1, 1);
    In/Out → (0.3, 0.4, 0.6, 0.7); middle speed = current speed, or 50% if at 100%; start/end 100%.
- **Speed ramp graph** (while ramped): box padding 8, radius 7, fill `field`; plot height 76. Y = log speed 10 %…1000 %
  (6 pt inset top/bottom), 100 % dashed reference line `ink(0.14)` [2,3]; area under curve `ink(0.05)`; curve
  1.5 pt `text` (smoothstep in log space). Dots 10 (held 12) `text` with 2.5 pt `field` ring. Dragging a dot shows
  its % beside it (mono 10.5) and moves the playhead to that frame (restored after); hit radius 10; flat middle
  line draggable vertically (±8 pt); slight snap to 100 %. Cursors: resize-LR / open-hand / resize-UD. Footer: mode
  pills **In** | **In/Out** (10 pt medium, 15 tall, picked fill `ink(0.14)`, inside a radius-4 `bg` tray) and
  "Length <clip length>" (10.5, mono value).
- **Transform** (collapsed by default; Reset when not identity; marked when not identity):
  - Scale: 5 %…1000 %, logarithmic, step 1, shown to tenths ("95.3%"). Inline zoom button (single clip): toggles a
    **Zoom** move ("Zoom: move between the full frame and this scale over the clip" / "Remove the zoom").
  - **Zoom graph** (single clip with zoom): like the ramp graph; Y = log scale 100 %…top where top steps 300 % →
    500 % → 1000 % (only grows); dots snap to frames, min gap 1 frame; top line sets scale (min 105 %). Footer: mode
    pills **In / In/Out / Out** and Smooth/Linear ease toggle (two 20×15 buttons with S-curve / straight glyph). Mode
    remembered in `zoomMoveMode` (default "in").
  - X / Y: in frame pixels from centre, step 1, tenths. If scale > 100 % (fills): X/Y say where it frames, range
    ±(scale−1)/2 × size (right/down positive; picture moves the opposite way). Else range ±(1+scale)/2 × size.
- **Transitions** (collapsed by default; marked when either side has one): rows **In** (from previous touching clip)
  and **Out** (into next): icon · label (52 wide) · MenuField None / — / Dissolve / Dip to Black / Wipe. When set:
  **Length** 0.1…5 s (default 0.5, 2 decimals "0.50s"). If the real span is shorter: "Shortened to 0.32s: no more
  media beyond the cut." or "Needs media beyond the cut to blend; try Dip to Black." (10 pt `textFaint`, indent 26).
- **Fade** (title "Fade" for visual-only or audio-only selections; "Video fade" + "Audio fade" when both; collapsed
  by default, marked when any fade): **Fade In** / **Fade Out** 0…min(duration, 10) s (min max 0.1), "0.00s",
  snapped to frames, can't exceed duration − other fade; trailing CurveMenu (default Linear). Icons: arrow→| and |→.
- **Grade** (visual clips; collapsed by default; Reset when not neutral):
  - Three colour wheels in a row: Shadows, Midtones, Highlights. Wheel 78 diameter, fill `field`, hue ring 3 pt
    angular gradient red→yellow→green→cyan→blue→magenta→red (opacity 0.6, 0.95 on hover/drag), crosshair
    `ink(0.1)`; puck 11 (13 dragging), white (accent when off-centre), 1px black@0.5 stroke. Drag sets x/y in unit
    disc (rounded to 0.01, dead zone 0.06 → 0). Double-click resets. Label 11.5 (`text` if active else `textDim`).
  - Exposure −2…+2 ("+0.00"), Contrast −50…50, Saturate −100…100, Temp −50…50, Tint −50…50 (integers; default 0).
  - Look: MenuField None / — / Warm film, Golden hour, Film print, Teal and orange, Pastel, Bleach bypass, Mono,
    Cool night / — / Load .cube… (file dialog; invalid → error "“x.cube” isn't a 3D .cube LUT this app can read.").
  - Intensity 0…100 % (shown only when a look is set; default 100 %; reset to 100 % when the look is removed).

```
┌ Toolbar 44 ──────────────────────────────────────────────────────────┐
```

App icon: `Assets.xcassets/AppIcon.appiconset` (16, 32, 128, 256, 512 @1x/@2x) — reuse for Tauri `icons/`
(generate .ico/.icns via `tauri icon`). Project file icon badge text "ROOM".

### 2.6 Waveform styling

Filled average-loudness (RMS) shape growing **up from the bottom** of the clip (not mirrored): top = clip top + 2, base
= clip bottom − 1; height = `clamp(rms × 2 × gainLinear, 0, 1) × room × 0.92`, min 0.75 pt (silence = thin line);
sampled every 1 pt on a grid tied to source time (no shimmer when scrolling; ramped clips map via table every 4 pt),
5-sample box smoothing. Fill: filmstrips on `rgba(204,204,199,0.7)`; off `rgba(224,247,230,0.55)`. Runs behind the
name. (Waveform mock "Filled loudness" pick; polish mock shows a mirrored version — code is bottom-up.)

## 3. Timeline interactions

### 3.1 Layout math (`TimelineLayout`)

| Constant | Value |
|---|---|
| ruler | 26 |
| zone (add-track drop zones, top & bottom) | 26 |
| gap between rows | 1 |
| divider between video and audio | 9 |
| header width | 176 |
| caption row | 30 (+1 gap) when the sequence has a caption track |
| fixedHeight | zone × 2 + divider = 61 |
| row height | default 62, range 30…110 (integer) |

Vertical order (content y from 0): [caption row 30 + 1] → video zone 26 → video tracks **highest index first**
(V_n … V1), each `rowHeight + 1` → divider 9 → audio tracks A1 … A_n each `rowHeight + 1` → audio zone 26.
Screen y = `ruler + contentY − scrollY`. Clip rect x = `start × pps − scrollX`, width `max(duration × pps, 1)`;
drawn inset 2 pt top/bottom and `min(0.5, w/4)` sides. New-track placeholder bands = zone inset 2 (height 22).

**Horizontal view**: `pps` (points per second) default 80, min `max(0.05, viewWidth / extent)`, max 2400;
`extent = max(30, duration × 1.3 + 10)` seconds; `scrollX ∈ [0, extent × pps − viewWidth]`.
**Vertical view**: "rows world" whose centre is the video/audio divider:
`rowsVisible = max(40, viewHeight − ruler)`; `rowsAbove = captionSpace + zone + nVideo × (row+gap) + divider/2`;
`rowsContent = fixedHeight + captionSpace + (nV + nA) × (row+gap)`;
`rowsWorld = max(rowsVisible, rowsVisible × row / 30, 2 × rowsAbove, 2 × (rowsContent − rowsAbove))`;
`scrollY ∈ [rowsAbove − world/2, rowsAbove + world/2 − rowsVisible]` (can be negative); centred =
`rowsAbove − rowsVisible/2`. All view changes go through one clamp (`setView`) so it is always stable/idempotent.
`fitRows` (on open/launch): `row = min(62, (rowsVisible + 15 − fixedHeight − captionSpace − 6)/tracks − 1)`; if
content fits centre it, else scrollY 0.

### 3.2 Zoom & scroll

- Menu/keys Zoom In/Out: ×1.4 / ÷1.4, **anchored on the playhead** (keeps its screen x if visible, else brings it to
  the centre).
- Zoom to Fit: `pps = (viewWidth − 80) / max(duration, 1)`, scrollX 0.
- Wheel/trackpad: with ⌥ or ⌘ held → zoom by `exp(dy × 0.012)` (dy ×8 for non-precise wheels); otherwise pan,
  locked to the dominant axis; non-precise wheels ×12 and a pure vertical wheel scrolls horizontally. Pinch → zoom by
  `1 + magnification`. Scrolling/pinching over the track headers is forwarded to the timeline.
  Windows: Ctrl+wheel zoom, Alt+wheel zoom; Shift+wheel horizontal pan — **UNSURE** (add Shift as well).
- Scroll/zoom bars: §1.6.
- While playing, if playhead x > width − 28 or < 0, view jumps so playhead sits 48 pt from the left.
- Autoscroll while dragging (scrub, move, trim, marquee) within 26 pt of left/right edge: velocity
  `min(34, distance × 0.6 + 4)` pt per 1/60 s (left only if scrollX > 0); re-applies the drag each tick.

### 3.3 Ruler

Background `panel`, 1 px bottom line `stroke`. Major step = first of the list (in seconds, with subdivision count)
whose pixel width ≥ 86 pt (and step ≥ 1 s or < 0.5 s): 1f(1), 2f(2), 5f(5), 10f(5), 1(4), 2(4), 5(5), 10(5), 15(3),
30(6), 60(6), 120(4), 300(5), 600(5), 900(3), 1800(6), 3600(6), 7200(4), 18000(5), 36000(5). Major tick 1×8 at
`ruler−9`, `ink(0.28)`; minor ticks 1×4 at `ruler−5`, `ink(0.13)`. Labels mono-digit 10 regular `textFaint` at
(x+5, 5): "m:ss" / "h:mm:ss"; when the step is < 1 s: timecode style → "m:ss:ff", simple style → "m:ss.cc".

### 3.4 Playhead, scrubbing, skimming

- **Playhead**: separate 16-wide overlay (never forces clip redraw). Accent fill: a cap 11 wide from y 5 with 3 pt
  rounded top corners, straight sides to y 13, narrowing to a point at y 19, then a 1 pt stem to the bottom. Position
  snapped to 0.5 pt. Hidden when off-screen.
- **Scrub**: mouse down on the ruler (not on a marker/range edge unless within 6 pt of the playhead, which wins) →
  drag moves the playhead; snaps to snap targets within 6 pt (haptic on new target); playhead always frame-snapped;
  audio scrub snippet if Audio Scrubbing on; shows a readout beside the flag: accent rounded rect (radius 4) at
  (x+10, y 4), mono 10 medium white, flipped to the left near the right edge. Fast approximate frame while moving,
  exact frame 90 ms after rest.
- The same readout shows while an inspector graph dot drags the playhead.
- **Skimming** (default on): hovering the canvas (not playing) shows that frame in the viewer without moving the
  playhead; skim line = 1 pt `ink(0.55)` from ruler down + 6×6 square at the ruler bottom. Leaving the canvas
  restores the playhead frame. Space while skimming plays from the skimmer (setting `playFromSkimmer`, default
  true) or from the playhead.
- Play from end restarts at start; with Loop on, playback repeats the in/out range if set, else whole timeline.
- Step frame ←/→; Previous/Next Edit jump to sorted unique {0, clip starts, clip ends, marker times} (±0.5 frame
  tolerance).

### 3.5 Selection

- Click clip body → selects it and its linked group (linked video+audio) unless already selected; ⇧-click toggles the
  linked group. Locked-track clips are not hittable.
- Click empty track space → clears selection (unless ⇧) and starts a **marquee** (accent 0.12 fill, accent 0.8 1 pt
  stroke): selects any intersecting unlocked clips (plus their linked partners), additive with ⇧. A marquee touching
  only captions selects captions.
- Caption row: click picks a caption (⇧ toggles), drag boxes captions, double-click seeks to it and focuses its text
  in the inspector. Captions don't move.
- ⌘A (Select All) selects all clips; Esc clears all selections (clips, media, folders, incoming) and returns to the
  Select tool (or exits viewer full screen).
- Mouse down on the timeline clears Media panel picks and focuses the timeline.

### 3.6 Hit zones (per clip, hit-tested in order)

1. **Fade dots** (only when a fade > 0 is set and clip width > 36): within 7 pt of a dot in the top 17 pt; dot x =
   clip edge ± fade × pps, clamped 6 pt inside the clip; overlapping dots: the longer fade wins (equal → side
   clicked). Cursor pointing hand.
2. **Edges**: within `min(7, max(2, width/4))` of left/right → trim; cursor resize-left-right.
3. **Gain line** (audio clips): within 3.5 pt of the line; cursor resize-up-down. Double-click resets to 0 dB.
4. **Body**: move.
- Gain line y = clip top + `norm × height`, `norm = db ≥ 0 ? 0.3 − db/12 × 0.2 : 0.3 + (−db/60) × 0.62` (0 dB at
  30%, +12 at 10%, −60 at 92%); dragging maps back (clamped 0.1…0.92, 0.1 dB, ≤ −59.5 → −60 / "−∞ dB"); bubble shows
  dB.

### 3.7 Move (drag body)

- Starts after 3 pt of movement; closed-hand cursor; ⌥ held = duplicate (copy cursor; originals stay, copies land).
- Moves all selected unlocked clips (incl. linked) by Δt (never before 0). Snapping (if active): each clip's start
  and end vs targets {0, markers, in, out, other clips' starts/ends, playhead} within **8 pt**; otherwise the grabbed
  clip's start snaps to frames.
- Vertical: grabbed clip's kind decides; track delta from the lane under the cursor; dropping in the "+ Video"/"+
  Audio" zone creates a new track; clamped to existing tracks; can't move onto a locked track. Linked partners on the
  other kind follow the same track delta only if they started on the matching index (V1↔A1) and the destination is
  free (or occupied only by the partner of a clip being overwritten).
- Dragged clips drawn at alpha 0.82 above originals (hidden); target lanes tinted `ink(0.035)`, new-track zones
  `accent@0.1`.
- Drop resolves overlaps by **overwriting** what's underneath (clips under are trimmed/split; linked halves stay
  linked); one undo step.

### 3.8 Trim (drag edge)

- All selected clips' same edge trim together (any track), plus linked partners.
- Snapping of the edge within 8 pt (else frame snap). Limits: can't cross neighbouring clips on the track, source
  media limits, minimum duration `max(1/60 s, 1 frame)`.
- **Sticky Edges** on (default off): trimming the end pushes/pulls everything touching after it (ripple); trimming the
  start keeps the clip's position and removes content from the front, also rippling — except a left edge that is
  "in the open" (not at t=0 and nothing touching it on its track) trims freely. If carried clips would collide,
  goes as far as fits (binary search).
- While trimming: lit 3.5 pt white edge bar on every clip being trimmed, duration bubble (timecode), and the viewer
  shows the new first (left) or last (right) frame with label "In"/"Out". Hovering a selected clip's edge lights that
  edge on all selected clips.

### 3.9 Fades on the timeline

Drag a fade dot → fade length (frame-snapped, ≤ duration − other fade); bubble "0.50s". Drawn as a black@0.55 shade
above the curve and a 1 pt white@0.85 curve line (24 steps, curve per clip setting). Dots: 4 radius (hot 5.5,
accent), white, 1 pt black@0.55 stroke, at y = top + 8. The longer fade's dot draws on top.

### 3.10 Cut tool

Cursor = scissors. Hover over a clip shows a 1.5 pt white line through the clip and its linked partners at the cut
time (snapped to targets within 6 pt, else frame); click splits there (must be > half a frame from either edge).

### 3.11 Markers and in/out

- **M** adds a marker at the (frame-snapped) playhead named "Marker N" (yellow) — or opens the existing marker there.
- Ruler drawing: `panel` backing behind label, 1 pt line in marker colour from y 4, flag polygon (0,4)→(8,4)→(6,8)→
  (8,12)→(0,12), name mono 10 medium `text@0.92` at x+11, y 5. A 1 pt line in the marker colour @0.45 runs down
  through the tracks.
- Click a flag/name (hit −4…+12+labelWidth) → marker popover (§1.11); drag (≥ 3 pt) moves it (snap 6 pt to targets
  + playhead, frame snap, live readout), one undo step. Clear All Markers in Mark menu.
- **I / O** set in/out at the playhead (setting one past the other clears the other); **⇧X** clears. Ruler: range
  lit `ink(0.06)`, white (`ink`) brackets 2 pt wide with 6×2 feet top and bottom pointing inward. Outside the range
  the tracks are dimmed with black@0.32. Range edges draggable on the ruler (within 5 pt; snap 6 pt; readout). The
  toolbar shows the range readout. Export offers "In to out".
- Snap targets always include 0, markers, in, out, clip edges (+ playhead for drags).

### 3.12 Drop behaviour (from Media panel or files)

- Accepted: Media items (`editroom:` pasteboard payload: asset ids, `text`, `solid`) and file URLs. Over the timeline
  or its track headers.
- Lane under cursor picks the video & audio target (over a video row Vn, audio goes to A(min(n, count))); over the
  zones → new track; locked targets fall back to the first unlocked track of that kind or a new track.
- Start = time under cursor (over headers → 0), snapped (start or end, 8 pt) or frame-snapped. Several items land end
  to end. Ghost clips drawn at alpha 0.55; file drags show a 5 s ghost labelled "name" / "name + N more".
- Drop inserts (overwrite semantics) as one undo step and selects only the new clips; files are imported first then
  placed. Text/solid default length 5 s; media = full length (frame-floored); images 5 s.
- Files dropped elsewhere in the window → imported into Media (window-wide drop catcher; promised files from Photos
  supported on macOS). Project files (`.room`/`.cutplay`) dropped → open the project (after save/discard prompt).

### 3.13 Context menus

- **On a clip** (selects it + linked if not selected): Split at Playhead (enabled when playhead inside) · Detach Audio
  (linked) · Reveal in Media · (source kinds) Freeze Frame at Playhead (video, not frozen, playhead inside) · Reverse /
  Play Forwards · (source-playing) Speed ▸ 25 / 50 / 100 / 200 / 400 / 800 / 1600 / 3000 % (ticked) · (visual)
  Transition In ▸ / Transition Out ▸ (None, —, Dissolve, Dip to Black, Wipe) · (audio) Even Out Levels · Add Captions
  / Remove Captions · (if fades) Remove Fades · — · (visual) Copy Grade · Paste Grade / "Paste Grade to N Clips" · —
  · (video) Match Sequence to Clip · — · Delete · Ripple Delete.
- **Empty track space**: Delete Gap (enabled if a gap there) · Close All Gaps on Track · — · Add Video Track · Add Audio
  Track · (if > 1 of that kind) — · Delete Track.
- **Caption row**: Edit Caption · Delete Caption(s) · Remove Captions from Clip · — · Show/Hide Captions · Delete
  Caption Track.

### 3.14 Clip rendering

- Fill (see §2.2), clipped to rounded rect radius `min(7, w/2)`; alpha 0.45 on locked tracks.
- Video: filmstrip tiles width `max(24, h × aspect)`, 1 pt dark gaps, alpha 0.88, graded with the clip's grade;
  source step = smallest power of two ≥ 1/16 s that keeps tiles ≥ one thumbnail wide; reversed/frozen/ramped handled;
  max 240 tiles. Image: tiled stills alpha 0.85. Audio: waveform (§2.6). Solid: 5 pt strip of its colour along the
  bottom. Text: fill only.
- Title strip (if w > 26 and h > 20): with filmstrips on video/image a black@0.45 band 17 tall at top. Label = clip
  name (+ "   Freeze" or "   NNN%", "   Reversed", audio "   ±x.x dB"), system 10.5 semibold white@0.95 with shadow
  (black 0.8, blur 2.5, y −0.5), at x+8 (after fade-in dot + 10), y+2.5, clipped 16 pt short of the right. Graded
  visual clips add a 9 pt six-segment colour wheel and the look name or "Graded".
- Border: selected = selection colour 1.5 pt; hovered = white@0.6 1 pt; else `clipStroke` (or tinted for flat
  colours).
- Transitions: hatched block over the span (band inset 3, radius 4, black@0.35, white@0.35 2 pt diagonal stripes
  every 7 pt, 1.5 pt white border @0.75 / 1.0 when selected).
- Snap guide: 1 pt `ink(0.9)` line spanning the dragged clips ±4 with 6 pt dots at both ends.
- Value bubble: `rgb(13,13,13)@0.92` radius 5, mono 10.5 semibold white, padding 7/3, 22 above the cursor, kept
  in bounds.
- Lanes: `lane`; off tracks (locked/hidden/inaudible) `bg` blended 40% toward `lane`.
- Captions: blocks inset 3 vertically, radius `min(5, w/2)`, fill `textClip`, text 10.5 medium white@0.92 when
  width > 18; selected stroke selection colour 1.5; hidden track alpha 0.45; empty: "Listening for what's said…" /
  "No speech heard in the captioned clips".

### 3.15 Track operations

Mute/solo/hide/lock toggles in headers (each an undo step). Locked tracks: clips dimmed, not hittable, can't receive
moves or drops. Duck Under another audio track by −6/−12/−18/−24 dB. Add/Delete track via headers, zones, menus;
can't delete the last track of a kind.

**Mapping rule for Windows/Linux**: `command` ⇔ Ctrl, `option` ⇔ Alt, `control` (⌃) ⇔ **UNSURE** (Win key is not
usable; treat macOS ⌃ combos as Ctrl+… only if not already taken, or drop). Store combos in a platform-neutral
form (e.g. `primary` modifier = ⌘ on mac / Ctrl on Windows) so saved shortcuts round-trip. Display: macOS glyphs
`⌃⌥⇧⌘` + key ("Space", "⌫", "⌦", arrows, "Home", "End", "↩", "⇥", "Page Up/Down", else uppercase); Windows "Ctrl+Alt+
Shift+Key", "Backspace", "Del", "Enter", "Tab".

**Dispatch rules** (must be replicated):
1. While Settings is recording a shortcut, no shortcut fires.
2. While the Magic show runs, keys go to it (any key skips to end).
3. In a text field: plain/⌥/⇧ keys type text, even if they are menu shortcuts (e.g. S, R, K, Delete) — the editor
   must not steal them; ⌘/⌃ combos still work.
4. Bare-key shortcuts only work in the editor window, with no sheet/popover/panel attached (not in Settings, export
   sheet).
5. ⌘-combos of menu actions go through the menu (so the menu flashes); everything else is handled by a window-level
   key handler.
6. Plain multi-character keys (Delete, Space, arrows…) are never given to menu items as key equivalents (so Delete
   in Settings/sheets never deletes clips) — menus show them without shortcut.
7. Esc (no modifiers): exits viewer full screen if on; else clears all selections and selects the Select tool.
8. Assigning a combo removes it from any other action (single owner).
9. ↑/↓ inside numeric fields step values instead (§1.5), never trigger edits.

Other built-in keys: ⌘A Select All (timeline), ⌘X/⌘C/⌘V Cut/Copy/Paste clips (timeline focus; Paste at playhead
makes fresh linked copies), ⌘, Settings, ⌘Q Quit, ⌥-drag duplicate, ⌘ held while dragging inverts snapping,
⇧-click extends selection, double-click resets gain line / colour wheel. In fields: Return commits, Esc reverts, Tab
moves to next field.

### 6.3 Opening and drag-drop of media

- Files opened from Finder/Explorer or dropped on the Dock icon: if the app was not running, it starts with a **new**
  project containing them (instead of reopening the last session); if running, they're handled in the existing window
  without re-presenting it.
- `handleOpen(urls)`: the first project file opens (after Save/Discard prompt); all non-project files import into
  Media; app activates.
- In-window drops: over timeline/headers → placed on the timeline where dropped (§3.12); elsewhere → imported into
  Media with the panel drop overlay; the dragged images vanish immediately (no fly-back animation).
- macOS file promises (Photos, Mail) are supported: placeholders "Importing…" until the file is written; promised
  files are held for unsaved projects and moved beside the project on first save. Windows has no equivalent (Explorer
  drops are plain paths) — skip; virtual-file drags from apps like Outlook are **UNSURE**.
- Linked folders: importing a folder mirrors it in Media and keeps following it on disk (adds, renames, moves,
  Trash).

## 7. SelfTest checklist (behaviours we must also test)

SelfTest is a headless mode `Editroom --selftest <mediaDir> <outDir>` that imports every file, builds an edit and
logs `NAME OK|FAIL` per check; related modes: `--format-check <outDir> <files…>`, `--bench <dir>`, `--bench-files`,
`--reverse-bench`. Other test flags seen: `--open`, `--library-width N`, `--settings-tab X`, `--show-agents`,
`--export-vertical`, `--play-export-preview`, `--dump-menu`, `--magic-local`, `--mcp`. The port should provide an
equivalent CLI/integration test harness.

**Engine / export**
1. Import every file in a folder; report kind, duration, size, fps, audio presence, whether ffmpeg conversion was
   needed (IMPORT OK/FAIL).
2. Base edit: 0–2 s normal speed, 2–3 s at 400 % (source 2–6 s), then a solid fading in; a half-size PiP clip in
   the top-right quarter; mono look + warm highlights grade on the sped-up part; dissolve between them; second
   source on V2. Export MP4 and WAV successfully.
3. **Gain**: a lone tone at +6 dB vs 0 dB measures correctly.
4. **Speed group**: changing speed on several clips keeps them butted; untouched clips are pushed, never overlapped.
5. **Speed ramp** 100→400→100 % over 4 s of footage: timing round-trips, footage span unchanged, split halves keep
   the curve, reversing mirrors it, flat/middle values right, exports.
6. **View limits**: any zoom/scroll/row request stays inside the bars and is stable under re-clamping; zoom-out
   floor, zoom-in ceiling, scroll before start, tallest/shortest rows; at smallest rows thumb fills bar and tracks
   centred; centred thumb ⇒ video/audio gap centred at rows 30/62/110 even with extra video tracks; zoom keeps the
   playhead's screen position unless a limit intervenes. `gripDrag` cases: (2,100,200,+30)→(70,230);
   (0,100,200,−30)→(70,230); (2,0,200,+30)→(0,230); (0,150,400,−30)→(120,400); (0,0,200,−30)→(0,200);
   (2,150,400,+30)→(150,400); (0,0,200,+30)→(30,170); (2,100,200,+500)→(0,400); (2,100,200,−500)→(140,160) with bar
   400, min 20, max 400; mirror 0 → only dragged end moves (0,200,−60 → 0,140); mirror ⅓ (100,200,−30 → 110,170)
   keeps a playhead at 25 %.
7. **Relink**: a project folder moved as a whole finds files by relative path; relinking one file finds siblings;
   skipped (not crashed) without fixtures.
8. **Reload**: a file overwritten with a shorter one is noticed, reopened, its clip cut to fit in one undo step;
   identity kept.
9. **Sticky edges**: shortening the first of three butted clips pulls the others back; growing pushes; speed change
   ripples; linked partner follows.
10. **Tracks**: old files without solo/lock decode; solo silences others; locked clips are excluded.
11. **Opening**: media isn't drawn as missing while loading; a genuinely missing file is, once looked for.
12. **Ripple Trim (Q/W)**: the clip under the playhead loses head/tail, gap closes on every track; with a clip
    selected only its tracks move; undo restores.
13. **Import shown**: hand imports pick and scroll to the files / folder tile; agent imports don't; Reveal in Media
    and Select All behave.
14. **Upscaler**: same orientation and colours as a plain resize, sharper edge; timing logged.
15. **Promised files**: held for unsaved project, moved beside it on first save (clip follows), unused held copies
    cleared.
16. **Replaced file in another format** (clip.mp4 → clip.mov): same item takes the new file, timeline clip stays;
    with two candidates nothing is guessed.
17. **Reload rotated file**: item becomes portrait and draws turned (pillarboxed).
18. **Folders**: linked folder mirrored and followed (adds, renames, folder move, removed file stays out, Undo brings
    back, Trash not followed, Delete Folder removes all, picking works).
19. **Zoom on Scale**: In, In/Out, Out; kept on its picture through trims/splits (in-out split → an in and an out);
    never past the picture edge; drawn zoomed; toggle on/off; linear vs smooth.
20. **Typed timecode** @30 fps: "1000"→10 s, "1:02:03"→62.1 s, "00:00:02:15"→2.5 s, "12"→0.4 s, "abc"→invalid.
21. **Transitions**: dissolve borrows the sped-up clip's unused head and ends at the cut; dip sits across the cut;
    with no spare media a dissolve uses what exists.
22. **Ducking**: A2 lowered while A1 has sound (file comparison).
23. **Loudness**: WAV exported at −14 LUFS measures −14 LUFS (and peak reported).
24. **Placement**: added text/solids land in the first open spot (free track at playhead, else next gap).
25. **Audio scrubbing**: mix rendered to memory with sound where the edit has it and silence after the end.
26. **Meters**: lit while playing, empty the instant playback stops.
27. **Gaps & paste**: a gap closes with linked audio following; close all gaps; paste makes fresh still-linked copies
    at the playhead.
28. **Overwrite links**: overwriting into the middle of a clip with its sound keeps both halves linked; overwriting
    picture only leaves the right picture half alone.
29. **Freeze frame**: split at playhead, 2 s hold inserted, rest moves along; exported frames across the hold
    identical.
30. **Reverse**: first frame = last of its source span and vice versa, same length, audio reversed too.
31. **In/out range**: range-only export has the range's length; markers survive save/load; old files open; snapping
    to range edges.
32. **Sticky edge attach rule**: left edge is attached at t=0 or against a clip, not in the open.
33. **Film print look** matches the approved mock colours (worst-case error threshold).
34. **Grade copy/paste**: whole grade onto every selected visual clip (not audio); one undo restores all.
35. **Export shapes**: vertical 9:16 export of 1080p is 1080 × 1920; moving the crop changes the content.
36. **Shortcuts**: Space→Play/Pause, ⇧S→Audio Scrubbing, ⌘S→Save, ⇧⌫→Ripple Delete; reassigning moves the key
    (P→Snapping, S→Loop takes from nobody), stealing (⇧S→Loop removes it from Audio Scrubbing), persistence across
    store reloads, reset all restores defaults, plain Delete never becomes a menu key equivalent while ⌘S does.
37. **Captions**: captioning a video uses its sound; words placed where said; follow clip moves/speed (moved 2 s,
    200 %); fixes apply one-for-one; a deleted caption drops its words; drawn white at caption height with the
    current word yellow; deleting all captioned clips removes the track; re-captioning restores words; typing fewer/
    more words redistributes timing.
38. **Media delete**: picked items deleted with Delete; one Undo brings them back; Redo again.
39. **Format check** (`--format-check`): per file import time/kind/size/fps/audio format/colour space; frames from
    playback, reversed copy, hover-preview thumbnails and export are produced; for SDR/HLG/PQ/Apple Log patch clips
    the six patch colours match expected sRGB (118,118,118), (235,235,235), (200,40,40), (40,170,60), (40,60,200),
    (224,172,105) within tolerance, alone and in a mixed-format timeline.

**Magic / AI / MCP** (owned by the Magic spec, listed for completeness): Magic history (in file, newest first, unique,
capped, undo-independent); AI result show (all clips fly in, ends where edits end); media search in everyday words
(ride→rollercoaster, party, city; nonsense finds nothing); @marker mentions (by name/colour, spans, title place, file
name wins); Local titles; Local captions; captions join the cut's undo step; Local adds clips at end/beginning/after
selection/before 2nd/inside a clip; combined asks as one plan; zoom tool for agents; Local zooms; auto planner (128
BPM beat, cuts on beats, no reused moments, ends on a bar, graded, titled); MCP tools (each call one undo step, clear
errors); newer MCP tools (markers, in/out, reframe, title style, solids, freeze, reverse, detach, duplicate, track
switches, search, export refused in Magic); Magic draft isolation & dependency-ordered replay; agent connect config
writing (Codex settings preserved, Claude extension manifest valid); music download (audio only, source noted); Local
improve (repeats removed, long shots trimmed, beat cuts, no gaps, song trimmed, doubled title removed, mentions,
moments).

**Perf benchmarks** (non-pass/fail): preview frame rate for 4K30/4K60 (+PiP, HDR) must meet the clip's fps; reverse
